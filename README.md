# Head First C#

Repositório criado durante meus estudos com o livro **Use a Cabeça: C#** (Head First C#), em sua edição mais recente, com o objetivo de aprofundar meus conhecimentos em **C#** e no ecossistema **.NET**, partindo dos fundamentos da linguagem até conceitos de orientação a objetos e consultas de dados.

O projeto é dividido em capítulos (`chapter_01` a `chapter_09`), cada um contendo os exercícios práticos propostos pelo livro, misturando aplicações de **console** e aplicações visuais em **WPF**.

## 🧩 O que estou estudando neste projeto

* Fundamentos da linguagem **C#** (variáveis, operadores, estruturas de controle)
* Criação de aplicações desktop com **WPF (Windows Presentation Foundation)**
* **Orientação a Objetos**: classes, objetos, encapsulamento, herança e interfaces
* Tipos de dados, valores e referências
* Enums, coleções genéricas (`List<T>`) e comparação/ordenação de objetos
* **LINQ** para consultas, agrupamento e junção de dados
* Boas práticas de organização de código e reaproveitamento entre projetos

## 📚 Sobre o projeto

Cada pasta representa um capítulo do livro e contém um ou mais exercícios/projetos independentes, evoluindo em complexidade conforme o aprendizado avança:

* **chapter_01** — Primeiros passos com C# e WPF (jogo da memória)
* **chapter_02** — Produtividade com C#: console e controles visuais
* **chapter_03** — Introdução a objetos e classes
* **chapter_04** — Tipos, valores e referências
* **chapter_05** — Encapsulamento
* **chapter_06** — Herança
* **chapter_07** — Interfaces
* **chapter_08** — Enums, listas e comparação de objetos
* **chapter_09** — LINQ

Cada capítulo possui seu próprio `README.md` com mais detalhes sobre os tópicos e exercícios específicos daquela etapa.
